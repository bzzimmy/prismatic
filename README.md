# Prismatic

A custom AI coding agent, forked from [Pi](https://github.com/earendil-works/pi).

## Packages

- **[coding-agent](packages/coding-agent)** — Interactive coding agent CLI
- **[agent](packages/agent)** — Agent runtime with tool calling and state management
- **[ai](packages/ai)** — Unified multi-provider LLM API
- **[tui](packages/tui)** — Terminal UI framework

## Development

```bash
npm install --ignore-scripts
./pi-test.sh         # run the coding agent from source
./test.sh            # run tests
```
